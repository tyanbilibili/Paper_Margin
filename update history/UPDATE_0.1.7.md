# Paper Margin v0.1.7

- 精读规范以 `工作流程.md` 为基准：结构体检、无损分段、先提取断言再写四问、页内复核、全文论证链与最弱一环。保留限定条件，区分作者主张、证据及推断；解析失败、未报告与表述冲突分别说明。字段与引用有程序校验，语义质量和图表的实际核对仍依赖模型及可读资料。网页版只给模型发送文本，不声称读过原始图像。
- 网页翻译选项右侧新增三种建议模式；Agent Skill 要求开始前询问。选择不需要时，不生成或显示建议。选择其余模式时，建议引用已精读段落，并默认折叠在原文附录上方。降重/降 AIGC 模式仅面向原创表达、独立论证与规范引用，不保证或规避检测分数。
- 两版支持 `.md`，沿用本地文字重排与定位，不执行内嵌 HTML、不加载外部图片，不是完整 Markdown 渲染器。
- 模型按内容选择流程、证据对照表或中心主题与分支视图，均保留段落链接。输出由程序渲染，不执行模型生成的 HTML。
- 旧任务没有建议偏好时默认不生成，旧总结没有可视化类型时默认流程视图。网页版建议失败可继续，不必重跑已完成的精读和总结。

验证：19 项 Python 测试（含 MCP stdio 回归），网页生产构建通过；Chromium 用模拟 API 验证三种模式、Markdown 导入、三种总结视图和离线导出。未调用付费模型验证学术解读质量。

部署：更新 `web/dist` 内全部内容；Agent 使用 `paper-margin-agent-v0.1.7.zip`，更新同名 Skill 并重新连接 MCP。已导出的 HTML 不会自动更新。
