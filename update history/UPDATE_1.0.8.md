# Paper Margin v1.0.8

## 阅读体验

- **领域专家视角**：两版提示词改为按用户指定的学术领域专家身份解读；网页版新增「学术领域（可选）」输入并写入任务 JSON，留空时由模型依据论文内容判断领域并说明。
- **新的总结结构**：新增 `overview`（1000–1500 字中文概述，引用具体内容、关键数据与实验结果，通俗解释新技术概念并加粗关键术语）与 `analysis`（六个 `###` 三级标题的深度分析：研究问题与价值、创新方法与技术背景、实验设计与关键结果、产业前景与机会、未来方向与挑战、局限与可借鉴思路）。
- **Markdown 排版**：批注与总结支持受限 Markdown（`###` 标题、列表、加粗、`>` 原文引用、表格）。渲染器先转义再生成标签，不执行模型返回的 HTML。
- **减少免责声明**：提示词要求直接给出有依据的分析与判断，只在解析缺损或数据缺失确实影响结论时说明。

## 性能

- 网页版单次精读批次由 6 段提升到 12 段，减少请求次数与重复上下文。
- 单块页不再调用模型做智能分段（网页版与 Agent 端均适用），直接视为一段。
- 总结请求不再重复携带 `method` 字段，降低输入 token。
- 允许按论证簇合并讲解（如三点式并列段落），不必逐段机械复述；每个段落仍保留自己的 `block_id` 与原文短引文。

## 仅网页版

- 新增四套个性主题：**羊皮纸**、**墨夜**、**朱砂**、**青瓷**；原「工作台」保留为默认主题。
- 主题写入任务 JSON，恢复任务与导出的离线 HTML 都会保留所选主题。

## 仅 Agent 插件版

- 工作流简化为「必要结构确认 → 必要 OCR/分段 → 论证簇精读 → 总结导出」，只做一次必要确认，不再逐页做页眉、引用编号等清单式检查。
- 静态 HTML 新增本地文本提取（跳过 script/style/iframe 等，保留图片 alt），`.html/.htm` 不再误走 Office 转换；静态阅读稿默认跳过 PDF 式栏序/页码体检。
- 保留的验证：OCR 门禁、来源覆盖、引用是否可定位、导出门禁。

## 兼容与验证

- 旧总结缺少 `overview`/`analysis` 时自动回退：`overview` 由原有四个字段拼接，`analysis` 为空；旧网页任务同样兼容。
- 回归：29 项 Python 测试（含 MCP stdio 流程与新增 `tests/test_v108.py`）全部通过；网页 TypeScript 检查与 Vite 生产构建通过。
- 未调用付费模型验证真实论文的解读质量；Markdown 渲染到浏览器中的视觉效果只做了构建级验证。

## 部署

- 网页：上传 `web/dist/` 内部全部内容（含 `assets/`、`ocr/`）。
- Agent：使用 `paper-margin-agent-v1.0.8.zip`，更新同名 Skill 后重新连接 MCP；已导出的旧 HTML 不会自动更新。
