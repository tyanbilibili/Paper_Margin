# v0.1.5 文档阅读工作台（视觉方向已获确认）

1. Agent新增prepare_document：DOC/DOCX/PPT/PPTX由本机LibreOffice或Windows Office+pywin32转换PDF，尽量保留版式；可用WPS手动导出PDF作为替代。宏禁用，文档不得来自不可信来源。转换仍可能有字体/排版差异。当前未实测本机Office COM实际转换；缺转换器会明确报错。网页版直接支持DOCX/PPTX文字重排，不保留图片、图表、复杂表格或公式；DOC/PPT/CAJ要求先转PDF。CAJ暂不原生支持。
2. 合并后的段落保留regions，逐来源区域分别框选；点击任一框同步高亮同段各框，不再跨栏使用大包围框。旧任务若未保存regions仍用原bbox，需要重新分段才能改善。来源块自身已跨栏混杂时仍需核对。
3. Agent读取返回前后页上下文，Skill要求先浏览全文再解释；网页同页固定前缀增加相邻页首尾各3块，并要求说明段落与前后论证的联系。上下文不是无限全文，不能保证自动消除所有理解错误。
4. 原文附录已有译文时同时列出，不翻译的任务不显示虚构译文。
6. Agent新增check_plugin_update，每次使用由Skill引导调用，24小时缓存GitHub公开Release元数据；只提醒并询问，不自动下载执行。离线失败不阻塞阅读。MCP工具共11个。无需GitHub凭据。
7. 网页模型设置标题旁加入圆圈问号，新页tutorial.html按用户指定的DeepSeek步骤说明三个输入框，并提示额度与Key保密。

验证：16项Python/MCP测试通过；浏览器合成DOCX/PPTX导入、双区域同步定位、译文附录和教程检查通过；TypeScript生产构建通过。新增ZIP依赖fflate安装时发现已知问题，已更新至修复版本，生产依赖审计0项已知漏洞。未用真实模型评估上下文理解质量，未实测Office转换、复杂Office布局与真实跨栏PDF精确度，未进行视觉像素冷读。
