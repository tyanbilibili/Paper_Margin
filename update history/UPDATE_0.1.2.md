# v0.1.2 阅读体验与成本优化

- 两版精读默认折叠，点击原文定位框自动展开对应项并收起前一个；也可手动切换。Agent 阅读器取消按原页 y 坐标撑开批注的空白间距，使用紧凑列表。长页若条目本身极多仍可能比原页长。
- 可复制原文采用正文阅读宽度、宋体/Times New Roman、首行缩进与段间距；显示时合并 OCR 硬换行，中文日期不再竖排。只改变显示，不修改来源文字或引文校验。公式、表格的显示式重排可能不保留数学结构，请核对原页。
- 网页版增加实际工作量进度：智能分段占0–20%，已完成精读占20–95%，总结完成后100%。这是阶段加权进度而不是预计剩余时间；失败/取消保留实际完成状态。分段阶段段落总数可能变化。
- 网页版同页精读请求共享固定 system 前缀（说明＋本页原文），变化消息只携带段落ID。服务商若支持精确前缀缓存，可复用同页后续批次；首次请求、短页、切换页或缓存失效仍按服务商规则计费。不能保证比未使用此策略一定便宜，尤其未命中时重复本页上下文有额外输入成本。
- 统计 API 返回的 usage：prompt_tokens、completion_tokens，以及 DeepSeek prompt_cache_hit_tokens 或 OpenAI prompt_tokens_details.cached_tokens。未返回字段时不代表确证未命中，页面提示无法判断。只显示本次打开页面累计的请求用量，刷新不保存，不估算美元费用。
- 缩短讲解要求为各字段通常1–2句，译文仍完整；已有批注与分段继续复用，不重复请求。Agent 版由宿主控制请求，因此仅提供固定前缀、按页批量、断点续做等指引，不声称控制宿主缓存。

验证：13项Python回归通过；网页生产构建通过；Chromium模拟API测试固定前缀一致、usage统计、100%进度、默认折叠、点击单项展开、日期重排及离线导出定位。Agent旧会话数据仅临时渲染检验交互，未改写用户原任务。未使用真实付费API确认缓存折扣，也未完成像素级视觉复核。
