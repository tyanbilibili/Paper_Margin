连接 DeepSeek：填写三个输入框

  1. 打开 DeepSeek 开放平台。
  2. 注册 / 登录账号，选择“API Keys”→“创建 API Key”，复制获得的 sk-… 字符串。不要把完整 Key 发到公开聊天、截图或仓库。
  3. 回到 Paper Margin：
    • Base URL 填 https://api.deepseek.com
    • 模型 ID 填 deepseek-flash
    • API Key 粘贴刚刚复制的 sk-…
    点击“测试连接”即可。模型可用性、额度与计费以平台实际提供为准。

API 调用可能收费，账号需有可用额度。测试连接不发送论文；精读前需确认向该服务发送文档文字。Key 仅保存在当前页面内存，不包含在任务或阅读 HTML 中。
